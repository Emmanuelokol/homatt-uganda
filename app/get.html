Install on Android

Android will ask you to allow installing this file — it is not from the Play Store. Tap Settings → Allow from this source, then Install. Installing over an older Homatt Clinic keeps everything already recorded.

This address always gives the newest version, so it never needs replacing.

The download looks stuck?

If it shows the same number on both sides — like 12.75 MB / 12.75 MB — then it has finished, even though it still looks busy. Android does this with app files.

Open My Files (or Files) → Downloads, and tap HomattHealth.apk. It will install normally.

If the two numbers are different, it really did stop. Tap it in your browser's Downloads list to resume — it carries on from where it reached rather than starting again.

Chrome says it is blocked or dangerous?

That is normal and it is not about this file. Chrome refuses every app file that does not come from the Play Store, however safe it is. Nothing is wrong with the download.

Pull down the notification, or open Chrome's Downloads, find the blocked line and tap Download anyway — it may be behind the small ⋮ or an arrow beside the message.

If you cannot find it, use Firefox, Samsung Internet or Opera instead — open this page there and tap the same button. It is the identical file, and it installs the same way.
